## 关于这个仓库

这是我用来锻炼 **Git、GitHub 和 Vibe Coding 能力**的长期练习仓库，记录从本地修改到远程协作的学习过程。

我会在这里练习管理版本、组织提交、处理分支，以及通过 Issue、Pull Request 和审核完成一次完整的迭代。同时，尝试用自然语言与 AI 沟通需求，理解生成的内容，再通过检查和反馈逐步完善结果。

## 练习目标

| 方向 | 我想练好的能力 |
| :--- | :--- |
| **Git** | 观察文件状态与差异，合理暂存和提交，理解分支、合并与冲突处理。 |
| **GitHub** | 管理远程仓库，清楚描述 Issue，提交易于审核的 PR，熟悉协作与自动化流程。 |
| **Vibe Coding** | 把想法拆成明确任务，与 AI 迭代实现，检查改动并验证结果。 |

## 迭代方式

```text
明确目标 → 小步修改 → 查看差异 → 验证结果 → 提交与 PR → 审核与复盘
```

每次练习尽量围绕一个具体目标展开：说明为什么改、理解改了什么、记录如何检查。让提交历史和讨论过程成为可以回看的学习记录。
