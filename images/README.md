# 图片资源

此目录用于存放本仓库 README、学习记录和协作说明中使用的图片与截图。

## 使用方式

- 将图片放入此目录，文件名建议使用小写英文字母、数字和连字符，例如 `git-branch-example.png`。
- 在仓库根目录的 Markdown 文件中，使用 `images/文件名` 作为相对路径；其他目录中的文档需按所在位置调整相对路径。

以下是引用写法示例，使用时请替换为实际存在的图片文件名：

```markdown
![Git 分支示意图](images/git-branch-example.png)
```

Git 不记录空目录。本说明文件让 `images/` 在尚未添加图片时也能随仓库保存。
